# PROMAX — Premium Property Management & Cleaning

A simple, fast, static landing page. No frameworks, no build step.

## Files

```
index.html   – the entire page
style.css    – all styles
script.js    – navbar, scroll animations, form
```

## Run locally

Just open `index.html` in a browser. That's it.

## Hosting

### Vercel (recommended)
1. Push this repo to GitHub (`abhinav349/Promax`)
2. Go to [vercel.com/new](https://vercel.com/new)
3. Import the repo — Framework Preset: **Other**
4. Deploy (no build command needed)
